2. Categorical Encoding & Normalization

Python [In 2]: Feature Encoding & Scaling 
# Map categorical strings to discrete numerical values
smoking_map = {'never': 0.0, 'No Info': 0.2, 'current': 0.4, 'former': 0.6, 'ever': 0.8, 'not current': 1.0}
data['smoking_history'] = data['smoking_history'].map(smoking_map)

# Min-Max Normalization across continuous features
data = (data - data.min()) / (data.max() - data.min())

# Ensure integer types for classification targets
data["hypertension"] = data["hypertension"].astype("int64")
data["heart_disease"] = data["heart_disease"].astype("int64")
data["diabetes"] = data["diabetes"].astype("int64")

3. Train-Test Split & Model Fitting

Python [In 3]: Model Training 
x = data.drop("diabetes", axis=1)
y = data.diabetes

# 70% Train, 30% Test split
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.3, random_state=42)

print("x train shape:", x_train.shape) # (70000, 7)
print("x test shape: ", x_test.shape)  # (30000, 7)

# Train Classifier
logreg = linear_model.LogisticRegression(random_state=42, max_iter=200)
logreg.fit(x_train, y_train)

test_score = logreg.score(x_test, y_test)
train_score = logreg.score(x_train, y_train)

print(f"Test Accuracy:  {test_score * 100:.2f}%")
print(f"Train Accuracy: {train_score * 100:.2f}%")

Clinical Feature Specifications

Detailed breakdown of the 8 features utilized by the model and their clinical significance.

Calibrated Weights
Feature Name Type / Range Relative Weight Clinical Significance & Description
blood_glucose_level Numeric (mg/dL) Very High (~32%) Direct postprandial and fasting glucose reading. Strongest positive predictor of acute diabetic risk.
HbA1c_level Numeric (%) Very High (~28%) Glycated hemoglobin representing average 3-month blood sugar levels. Critical diagnostic threshold at ≥ 6.5%.
bmi Numeric (kg/m²) High (~16%) Body Mass Index. Overweight (≥ 25) and Obesity (≥ 30) drastically increase insulin resistance.
age Numeric (Years) Moderate (~12%) Age in years. Risk exponentially rises after age 45 due to progressive pancreatic beta-cell dysfunction.
hypertension Binary (0 / 1) Factor (~5%) High blood pressure indicator. Strongly associated with metabolic syndrome and cardiovascular risk.
heart_disease Binary (0 / 1) Factor (~4%) History of cardiovascular disease or coronary artery disease.
smoking_history Categorical (6 levels) Factor (~3%) Categorized into never, current, former, not current, ever, and No Info.
